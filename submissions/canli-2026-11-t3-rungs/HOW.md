Construction: Sherwood covering perfect hash families of strength 3 (n x k arrays of points of the affine plane AG(2, q), every vector with first coordinate 1), each giving CA(n(q^3 - q) + q; 3, k, q) by the theorem of Sherwood, Martirosyan and Colbourn (2006): SCPHF(16; 90723, 4^2, 3), SCPHF(11; 17873, 5^2, 3) and SCPHF(6; 11288, 13^2, 3). Each was grown column by column by a randomized search: a new column is a point in every row such that every set of three columns keeps a row in which its points are not on one line; when no column fits after a number of tries, the column with the fewest conflicting pairs is added and old columns covering those pairs are removed.

Built from: nothing for q = 4 and q = 5 (the searches started from an empty array); for q = 13, the table's 10,000-column family table/certificates/CPHF_6_10000_13_3.txt, given to the search as its start (PQ_START); since the search can remove columns, the new family does not contain it unchanged.

Program: https://github.com/arhancanli/quantavane-covering-arrays/blob/a31a18e/code/search/pq_cphf3big_v3.c (MIT; built with `cc -O3 -march=native -o pq_cphf3big pq_cphf3big_v3.c -lm`), run as `pq_cphf3big q n 100000 CPU SEED OUT STALL 3 16` (at most 100,000 columns, CPU seconds and stop after STALL seconds without a new best, at most 3 conflicting pairs for a column added that way, 16 tries per column): q = 4, n = 16: CPU 20000, STALL 3600, SEED 11; q = 5, n = 11: CPU 600, STALL 200, SEED 21; q = 13, n = 6: CPU 600, STALL 200, SEED 21, PQ_START as above. The searches stopped after STALL seconds without a new best (q = 4, 5) or on the time limit (q = 13), so a rerun with the same seed may stop at another width; the family files here are the certificates. The families were converted from our coding of GF(q) to the Conway coding of tools/cphf/cphfcheck.c where they differ. Every family was checked exactly three times on all triples of columns: by our checker pq_scphf3_bigcheck.c on our coding, again by it on each file here in the Conway field, and by fullcheck3.c, a second checker written separately from the search and from pq_scphf3_bigcheck.c (both at github.com/arhancanli/quantavane-covering-arrays/tree/a31a18e/checker). The q = 4 family and its three logs are released in that repository (families/CA_964_3_90723_4.cphf.txt, checks/).
